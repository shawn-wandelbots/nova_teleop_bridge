Take control with the controllers

  • X + Y + A + B together, then release — calibrate (stand in the robot's pose first).
  • Hold both grips — the robot follows your arms. Let go and it pauses.
  • Click both thumbsticks — emergency stop.
  • If the headset stream stops for 2 seconds the robot pauses by itself and asks for a new calibration.

Record episodes

One episode is one attempt at the task. The robot records its camera video and joint data, keeps the episode only until your server has confirmed it is stored intact, then deletes its own copy.

Hands and fingers

The index trigger closes the hand. Which fingers close is chosen with the controller buttons, separately for each hand. For "only two fingers, the rest open", step once to Pinch. The robot most likely starts in Grasp each time teleoperation mode is started.

Settings

Data collection

The robot uploads the recording unchanged. Converting it to a LeRobot dataset happens on the server. Depth is not recorded: the robot's built-in depth pictures cannot be read on this computer.
